# Overview

This project is an R-based sports analytics script that demonstrates core data manipulation, functional programming, and spatial data visualization using open-source football data.

Using packages like tidyverse, StatsBombR, and ggsoccer, the software extracts event-level match data, processes spatial coordinates, and builds custom pass networks and spatial shot maps.

[Software Demo Video](https://youtu.be/TKRTQ3dUdD8)

# Development Environment

RStudio Desktop (Posit): Integrated Development Environment (IDE) used for writing, debugging, and executing scripts.

R is a statistical computing and graphics language widely recognized as an industry standard for statistics, data science, spatial analysis, and data mining.
